**Title:** Bug-to-PR Room: 4 Claude Code agents, 1 Discord room, 1 human gate (Switch hackathon)

**Description:**

Four Claude Code agents (triager, repro, fixer, reviewer) work one bug inside a Discord room, built on Switch. A human posts the bug and a rule, the reviewer rejects a patch that breaks the rule, the fixer corrects it, and only the room's creator can approve. Agents never merge: the human clicks Merge on GitHub.

Everything shown is one real, unedited run (sped up where labelled). Animations are labelled "illustration". The honest limits are on screen and in the README: the gate is enforced by instructions, not code; three agents run with permission prompts off; the rejection is likely, not scripted.

Code, README and the recorded transcript: https://github.com/Guten-Morgen1302/bug2pr-room
Demo repo the agents open PRs against: https://github.com/Guten-Morgen1302/bug2pr-demo
